# Music Store Sales Analysis | PostgreSQL

## Project Overview

Built and analyzed a relational music store database using PostgreSQL to perform customer, revenue, and genre analysis.

## Tools Used

* PostgreSQL
* SQL

## SQL Concepts Used

* Joins
* Subqueries
* CTEs
* Window Functions
* Aggregate Functions

## Analysis Performed

* Customer spending analysis
* Revenue trends
* Genre popularity
* Artist performance
* Country and city-wise analysis
* Running cumulative revenue

## Business Insights

Identified top-performing customers, highest revenue-generating cities, and popular music genres using analytical SQL queries.
